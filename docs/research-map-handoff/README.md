# 交接包：研究地图（Research Map）功能接入

> 给使用 Claude Code 的开发者。目标：把已完成的可视化页面 `research-map.html` 接入 Zotero 插件，让它显示**真实数据**并打通 PDF / Notion 解读等功能。

---

## 这个包是什么

- `research-map.html` —— **已完成的生产级前端页面**，不是需要你重写的设计稿。单文件、纯前端、零依赖、响应式、支持深色模式。
- 它**完全由一个全局变量 `window.GRAPH` 驱动**，UI 与数据彻底解耦。
- **你的工作不是改 UI**，而是：①让插件在加载页面前注入 `window.GRAPH`；②实现页面里几个外部动作的回调（打开 PDF、打开 Notion）。
- 页面内目前有一段带注释的**演示数据**（注释已标明"可整段删除"）。接入真实数据后删掉它即可；拿不到数据时页面会自动显示空状态。

详细字段定义见 `DATA_CONTRACT.md`，分步任务见 `TASKS.md`。

---

## 保真度

**高保真（hifi）。** 颜色、字号、间距、动画、交互均为最终态，**请勿改动 UI**。语义色约定（贯穿全页，改动会破坏一致性）：

| 含义 | 颜色族 | 浅色主值 | 深色主值 |
|---|---|---|---|
| 研究问题 problem | 紫 | `#7c3aed` | `#a78bfa` |
| 方法/概念 concept | 青绿 | `#0d9488` | `#2dd4bf` |
| 空白/可做 gap | 琥珀 | `#d97706` | `#fbbf24` |

字体走系统栈（`-apple-system / PingFang SC / Microsoft YaHei …`），无需引入 webfont。

## 页面结构（已实现，仅供你理解数据如何被消费）

1. **顶部指标卡** —— 论文数 / 核心问题数 / 方法数 / 可做方向数（数字滚动动画）。
2. **发表趋势** —— 按年月的可横向滚动柱状图；hover 显示当月论文清单。数据来自 `paper_dates`。
3. **论文贡献流** —— 时间轴卡片，每篇标出核心贡献点；**点击卡片打开论文详情抽屉**。
4. **按核心研究问题聚类** —— 每个问题一个区块，按论文数排序，含权重条、解决方法、该方向空白、可展开的论文清单。
5. **可做方向 · 研究机会** —— 每个 gap 画成"研究问题 → 已有方法 ✓ → ╳断点 → 待补空白"的闭环断点图，并列出"已有工作做了什么 / 为什么留白"。
6. **论文清单** —— 全部论文，可排序/搜索；**点击任意行打开详情抽屉**。
7. **论文详情抽屉（右侧滑入）** —— PDF 全文、AI 解读（Notion）、它在图谱中的位置、摘要、学术脉络、相关论文。这是接入工作量最大的部分。

---

## 交互与状态（已实现，你只需供数）

- 搜索框：过滤问题聚类与论文清单（纯前端，无需你处理）。
- 类型筛选 chip：按 `concept.kind` 高亮/淡化方法。
- 问题区块展开/收起；hover 方法/空白显示 `description`/`rationale` 浮层。
- 论文详情抽屉：`Esc` 或点遮罩关闭；抽屉内节点可点击跳回对应图谱区块；相关论文可继续跳转。
- 所有动画用 CSS transition + `IntersectionObserver`，并带 JS 安全网兜底；尊重 `prefers-reduced-motion`。

唯一需要你实现的"外部动作"：
- **打开 PDF** —— 页面用 `papers_meta[key].pdf` 的值生成 `<a href>`。给 `zotero://open-pdf/...` 就能在 Zotero 内打开；给 `file://` 用系统阅读器；给 `http(s)/blob` 会直接内嵌预览。
- **打开 Notion** —— 用 `papers_meta[key].notion_url` 生成外链按钮。
- **AI 解读内嵌** —— 填 `papers_meta[key].analysis`（结构化分段）即可直接渲染在抽屉里，**无需打开 Notion**。
